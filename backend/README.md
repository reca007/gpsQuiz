# GPSQuiz API

Render-ready backend for classroom demos.

## Endpoints

- `GET /health`
- `GET /api/quizzes`
- `POST /api/quizzes`
- `GET /api/leaderboard`
- `POST /api/leaderboard`
- `POST /api/ai/generate`

## Local test

```bash
cd backend
npm install
npm test
npm start
```

Then open `http://localhost:3000/health`.
